# Reference Tables

## Categories

Таблиця `categories` — категорії страв меню.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `name` | text | Назва категорії |
| `slug` | text | SEO-слаг |
| `cover` | text | URL зображення |
| `description` | text | Опис |

## Products

Таблиця `products` — страви.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `name` | text | Назва страви |
| `slug` | text | SEO-слаг |
| `cover` | text | URL зображення |
| `price` | numeric | Ціна (зберігається як рядок у JSON) |
| `description` | text | Опис |
| `createdBy` | uuid | Посилання на `users.id` |
| `createdAt` | timestamp | Коли створено |

## Tags

Таблиця `tags` — теги для фільтрації.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `name` | text | Назва тегу |
| `slug` | text | SEO-слаг |

## Ingredients

Таблиця `ingredients` — склад страви.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `productId` | uuid | Посилання на `products.id` |
| `name` | text | Назва інгредієнту |
| `quantity` | numeric | Кількість (зберігається як рядок) |
| `unit` | text | Одиниця виміру (г, мл, шт) |

## Inventory

Таблиця `inventory` — складські залишки; низький залишок — `quantity <= 10`.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `name` | text | Назва предмета |
| `slug` | text | SEO-слаг |
| `quantity` | numeric | Кількість (зберігається як рядок) |
| `unit` | text | Одиниця виміру |
| `cover` | text | URL зображення |
| `updatedAt` | timestamp | Коли останнє оновлення |
