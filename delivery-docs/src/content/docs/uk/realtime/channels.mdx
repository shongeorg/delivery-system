# Канали

- `order:<uuid>` — єдиний канал з перевіркою доступу. Використовується для статусу замовлення, локації кур'єра та чату конкретного замовлення.
- `orders` — умовний канал для сумісності з кур'єрським застосунком. Сервер приймає, але `new_order` / `order_updated` і так йдуть глобально.
