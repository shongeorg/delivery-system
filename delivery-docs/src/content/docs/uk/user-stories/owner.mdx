# Власник

Панель власника (`ower-panel`, порт 3034) — це бек-офіс керування. Роль `admin` входить у ту саму панель: її API дозволяє `owner` і `admin`, а UI-гард (`src/components/RoleGuard.tsx`) пускає лише `owner`.

## US-17. Дашборд ✅

`/` показує дохід (день / тиждень / місяць), чистий прибуток, активні замовлення, середній чек, персонал, топ-продукти й низький залишок. Дані оновлюються кожні 15 с (`refetchInterval: 15000`).

## US-18. Персонал і зарплати ✅

- `/staff` — 33 акаунти; `/staff/:id` — роль, блокування, базова ставка, бонус, валюта.
- `/payroll` — виплати й бонуси.

Кожна зміна пишеться в `audit_logs`.

## US-19. Фінанси ✅

`/finances` — дохід (лише замовлення зі статусом `paid`), payroll, витрати, чистий прибуток, денний графік, а також створення й видалення витрат.

## US-20. Кухня й кур'єри ✅

`/kitchen` — черга за статусами, час очікування та **призначений кур'єр** (ім'я, телефон) для замовлень у статусі `on_the_way`.

Обмеження: живої карти кур'єрів у owner-панелі немає. Позиція доступна через `GET /orders/:id/tracking` (роль `owner` дозволена), але UI її не показує.

## US-21. Налаштування й аудит ✅

- `/settings` — назва, телефон, адреса, години, валюта, податок, вартість доставки.
- `/audit-logs` — журнал дій.

## US-22. Чат із клієнтами 🟡

API дозволяє `owner`/`admin` читати й писати в чат замовлення, але окремого екрана для цього в owner-панелі немає.
