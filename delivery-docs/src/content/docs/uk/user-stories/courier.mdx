# Кур'єр

## US-7. Побачити доступні доставки ✅

`/orders` у `courier-app`: вкладки Available (`ready`), Active (`on_the_way`), Completed (`delivered`), статистика, автоперезавантаження 15 с.

Обмеження: список **не** фільтрується за кур'єром — це всі доставки системи.
