# UI чату

Чат замовлення використовує той самий бекенд, але кожен застосунок рендерить його по-своєму й підписує відправника на власний лад.

| Застосунок | Де | Особливості |
|------------|----|-------------|
| `frontend` | блок «Chat with courier and support» на `/orders/:id` | бульбашки: свої праворуч, інші ліворуч; `user` → «You» |
| `courier-app` | картка «Chat» на `/orders/:id` | `courier` → «You», `admin` → «Support», `user` → «Customer» |
| `ower-panel` | API доступне (роль `owner`/`admin`), окремого екрана немає | — |

## Підписи відправників у `frontend`

Сторінка клієнта зіставляє повідомлення з підписом і вирівнює його за `sender`:

| `sender` | Підпис | Вирівнювання |
|----------|--------|--------------|
| `user` | `You` | праворуч |
| `courier` | `Courier` | ліворуч |
| `admin` | `Support` | ліворуч |

## Підписи відправників у `courier-app`

Застосунок кур'єра підписує ті самі значення `sender` з погляду кур'єра:

| `sender` | Підпис |
|----------|--------|
| `courier` | `You` |
| `admin` | `Support` |
| `user` | `Customer` |

Повідомлення доставляються наживо всім учасникам замовлення каналом `order:<id>`. Про механіку доставки — у [Чат замовлення](/uk/tracking-chat/order-chat), про саму сторінку — у [Сторінка трекінгу клієнта](/uk/tracking-chat/customer-tracking).
