# Витрати

## Список витрат

`GET /owner/expenses` — Список витрат.

## Створення витрати

`POST /owner/expenses` — Створити витрату. `{ title, category, amount, note }`.

## Видалення витрати

`DELETE /owner/expenses/:id` — Видалити витрату.
