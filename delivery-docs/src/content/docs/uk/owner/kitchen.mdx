# Кухня

`GET /owner/kitchen` — черга за статусами, час очікування, **призначений кур'єр** (ім'я, телефон) для `on_the_way`.

Обмеження: у панелі власника немає живої карти кур'єра; позиція доступна через `GET /orders/:id/tracking` (роль `owner` дозволена), але UI її не показує.
