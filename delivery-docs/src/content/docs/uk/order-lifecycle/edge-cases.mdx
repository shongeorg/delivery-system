# Крайові випадки

## Два кур'єри одночасно

Race condition: обидва проходять перевірку. У тесті другий отримав `409`, але гарантії на рівні БД (unique/умовний UPDATE) немає.

## Клієнт не дав точку

`lat/lng = null`. Трекінг показує адресу й телефон, маршрут будується лише якщо є позиція кур'єра.

## Кур'єр без геолокації

Кнопка «Share my location» неактивна, OSRM-маршрут не будується — це очікувана поведінка, а не помилка.

## Старі замовлення

У БД є тестові записи 241-денної давнини; вони впливають на лічильники, але не на «сьогоднішні» метрики.

## Скасування доставленого замовлення

Матриця забороняє; прямого ендпоінта немає.
