# Правила кур'єра

## Дозволені статуси

Для кур'єра дозволені лише `on_the_way` і `delivered`.

## Прийняти та поставити on_the_way

`PATCH /orders/:id/status { on_the_way }` — Кур'єр приймає замовлення.

Бекенд перевіряє:

1. Статус замовлення мусить бути `ready`.
2. Замовлення ще не повинно мати призначеного кур'єра (`courierId` = null).
3. Перевірка `order already accepted by another courier` → `409`.
4. Перевірка `order assigned to another courier` → `403`.

Після успішних перевірок `courierId` встановлюється в ID користувача кур'єра.

## Позначити як delivered

`PATCH /orders/:id/status { delivered }` — Кур'єр позначає замовлення доставленим.

Можливо лише після `on_the_way`. Інші переходи через цей ендпоінт заборонені.

## Скасування для кур'єра

Для кур'єра ендпоінта скасування немає. Кур'єр може лише просувати статус через `PATCH /orders/:id/status`.

Якщо кур'єру треба скасувати, він має повідомити через чат або підтримку.
