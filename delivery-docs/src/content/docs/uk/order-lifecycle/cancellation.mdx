# Скасування

## Ендпоінт скасування

`POST /orders/:id/cancel` — Скасувати замовлення.

### Скасування клієнтом

Можна скасувати лише власне замовлення у статусі `created` або `paid`.

### Скасування власником/адміністратором

Можна скасувати у статусі `created` або `paid`.

### Важливо

Після статусу `cooking` скасування через цей ендпоінт повертає `400`.

Змінити статус на `cancelled` для пізніших статусів можна лише через `PATCH /orders/:id/status` з роллю staff.
