# Owner Panel (React)

Панель власника: єдиний центр керування рестораном. Показує живі бізнес-метрики й дає змогу власникові керувати персоналом, зарплатами, фінансами, кухонним оглядом і налаштуваннями ресторану. Побудована на **React 18**, **react-router**, **TanStack Query**, **axios** і **recharts**. Працює на порту `3034`.

## Стек, порт, роль

| Стек | Порт | Роль |
|------|------|------|
| React 18 + react-router + TanStack Query + axios + recharts + Tailwind 3 | `3034` | Власник: аналітика й адміністрування (лише `owner`) |

## Маршрути

Описані в `src/App.tsx`:

| Маршрут | Екран |
|---------|-------|
| `/login` | Вхід |
| `/` (`index`) | Дашборд |
| `/staff` | Список персоналу |
| `/staff/:id` | Деталі працівника |
| `/payroll` | Виплати із зарплат |
| `/finances` | Фінанси й витрати |
| `/kitchen` | Жива кухонна черга |
| `/settings` | Налаштування ресторану |
| `/audit-logs` | Журнал аудиту |

Усе під `/` загорнуто в `OwnerGuard` і рендериться в `Layout` (темне бокове меню Dashboard / Staff / Payroll / Finances / Kitchen / Restaurant / Audit Logs).

## Керування станом

- **TanStack Query** зберігає ввесь серверний стан; кожна сторінка визначає власний `queryKey`, а мутації інвалідовують відповідні запити.
- **Контекст авторизації** в `src/hooks/useAuth.tsx` (`AuthProvider` / `useAuth`) надає `user`, `isLoading`, `login`, `logout` та відновлює сесію через `GET /users/me`, якщо є `accessToken`.
- Локальний стан сторінок — через `useState` (фільтри, форми, модалки).

## Як застосунок говорить з API

- `src/api/axios.ts` — інстанс axios із зашитою базовою адресою `http://localhost:3000`.
- Інтерсептор запиту додає `Authorization: Bearer <accessToken>`.
- Інтерсептор відповіді обробляє `401`: робить один `POST /auth/refresh`, зберігає нову пару й повторює запит; якщо оновлення не вдалося — чистить токени й переходить на `/login`.
- Усі ендпоінти власника згруповано під `/owner/*` в `src/api/owner.ts` (`getOverview`, `getStaff`, `updateStaff`, `updateSalary`, `getPayroll`, `createPayroll`, `getFinances`, `getExpenses`, `createExpense`, `deleteExpense`, `getKitchen`, `getSettings`, `updateSettings`, `getAuditLogs`).
- Полінг: дашборд кожні `15 с`, кухня кожні `10 с`, журнал аудиту кожні `30 с`; решта сторінок тягне дані на вимогу.

До того ж: [Архітектура](/uk/архітектура), [Таблиці панелі власника](/uk/таблиці_панелі_власника).

## Авторизація та ролі

- `OwnerGuard` (`src/components/OwnerGuard.tsx`) перекидає на `/login`, якщо `user` немає, і показує «Access denied», якщо `user.role !== 'owner'`. Тобто UI доступний лише власникові, хоча бекенд-API `/owner/*` дозволяє ще й `admin`.

## Ключові реалізовані фічі

- **Дашборд**: виторг за день / тиждень / місяць / весь час, кількість замовлень і середній чек, місячні фінанси (зарплати, витрати, чистий прибуток), персонал за ролями, топ-товари, залишки з низьким рівнем і останні замовлення.
- **Персонал**: пошук і фільтр за ролями, зміна ролі, блокування/розблокування та редактор зарплати (`SalaryModal`).
- **Деталі працівника**: зарплата, бонус і історія виплат конкретної людини.
- **Зарплати**: виплати типу salary/bonus із підсумками за період.
- **Фінанси**: виторг / зарплати / витрати / чистий результат за діапазон дат із лінійним графіком `recharts` та CRUD витрат.
- **Кухня**: жива черга з вкладками статусів і попередженнями про час очікування.
- **Налаштування ресторану**: назва, контакти, години роботи, валюта, ставка податку, вартість доставки, логотип і обкладинка.
- **Журнал аудиту**: журнал дій із пошуком за сутністю, користувачем і деталями.
