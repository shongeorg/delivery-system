# Коди помилок

Помилки — це JSON-об'єкти з повідомленням `error` та HTTP-кодом `code`:

```json
{ "error": "Order not found", "code": 404 }
```

## Коди стану

| Код | Коли |
|-----|------|
| 200 | Успіх |
| 201 | Створено (замовлення, повідомлення) |
| 400 | Невалідне тіло або недозволений стан |
| 401 | Немає або прострочений токен |
| 403 | Роль або чужий ресурс |
| 404 | Не знайдено |
| 409 | Конфлікт переходу статусу або замовлення вже прийняте іншим кур'єром |
| 502 | Зовнішній сервіс (Nominatim) недоступний |

## Примітки

- Необроблені помилки повертають `500 Internal server error`.
- Невідомі маршрути повертають `404 Not found`.
