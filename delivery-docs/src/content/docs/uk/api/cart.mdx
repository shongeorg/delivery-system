# Кошик

Кожен маршрут кошика вимагає `Authorization: Bearer <accessToken>` і працює з кошиком поточного користувача.

## Ендпоінти

| Метод | Шлях | Доступ | Опис |
|-------|------|--------|------|
| GET | `/cart` | автентифікована | `{ cart, items }` |
| POST | `/cart/items` | автентифікована | `{ productId, quantity }` |
| PATCH | `/cart/items/:id` | автентифікована | Кількість |
| DELETE | `/cart/items/:id` | автентифікована | Прибрати позицію |
| DELETE | `/cart` | автентифікована | Очистити |

## Отримати кошик

`GET /cart` повертає кошик із позиціями; якщо його немає, створюється порожній:

```json
{
  "cart": { "id": "…", "userId": "…", "createdAt": "…", "updatedAt": "…" },
  "items": [
    { "id": "…", "cartId": "…", "productId": "…", "quantity": 2, "product": { … } }
  ]
}
```

## Додати позицію

`POST /cart/items`

```json
{ "productId": "…", "quantity": 2 }
```

`quantity` — додатне число. Якщо продукт уже в кошику, кількості додаються. Відповідь `200`: `{ "success": true }`. Помилки: `404 Product not found`.

## Змінити кількість

`PATCH /cart/items/:id`

```json
{ "quantity": 3 }
```

`quantity` — додатне число. Повертає `{ "success": true }`. Помилки: `404 Cart item not found`.

## Прибрати / очистити

`DELETE /cart/items/:id` прибирає одну позицію; `DELETE /cart` видаляє всі позиції. Обидва повертають `{ "success": true }`.
