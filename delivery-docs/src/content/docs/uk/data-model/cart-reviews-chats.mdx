# Кошик, відгуки, чати

## Кошик

Таблиця `carts` — один кошик на користувача.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `userId` | uuid (unique) | Посилання на `users.id` |
| `updatedAt` | timestamp | Коли останнє оновлення |

Таблиця `cart_items` — позиції кошика.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `cartId` | uuid | Посилання на `carts.id` |
| `productId` | uuid | Посилання на `products.id` |
| `quantity` | int | Кількість |

## Відгуки

Таблиця `reviews` — відгуки; унікальний на пару user+product.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `userId` | uuid | Посилання на `users.id` |
| `productId` | uuid | Посилання на `products.id` |
| `rating` | int | Рейтинг 1-5 |
| `text` | text | Текст відгуку |
| `createdAt` | timestamp | Коли створено |

## Чати

Таблиця `chats` — чат. `orderId` — чат по замовленню; старі записи без `orderId` — клієнт ↔ адмін.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `userId` | uuid | Посилання на `users.id` |
| `orderId` | uuid (unique) | Посилання на `orders.id` |

Таблиця `messages` — повідомлення; `sender` = `user` (клієнт) · `courier` · `admin`.

| Поле | Тип | Призначення |
|------|-----|-------------|
| `id` | uuid | Унікальний ідентифікатор |
| `chatId` | uuid | Посилання на `chats.id` |
| `sender` | text | Від кого: `user`, `courier`, `admin` |
| `text` | text | Текст повідомлення |
| `createdAt` | timestamp | Коли створено |
