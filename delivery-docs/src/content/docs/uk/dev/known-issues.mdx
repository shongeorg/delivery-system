# Відомі проблеми

## Поведінка

- **Геолокація в тестовому браузері.** У тестовому Chrome геолокація має стан `denied`, тому маршрут кур'єра будується без стартової точки. Код обробляє це чесно — кнопка «Share my location» неактивна, карта показує адресу, — але в такому браузері OSRM не намалює маршрут.
- **Готівка.** Замовлення з `paymentType: cash` створюється з `paymentStatus: pending` і не має окремого ендпоінта «оплачено готівкою». Дохід у фінансах рахує лише замовлення зі статусом `paid`, тому готівкові замовлення туди не потрапляють.
- **Адмін-панелі немає.** Роль `admin` користується owner-панеллю. Її API дозволяє `owner` і `admin`, але UI-гард пускає лише `owner`.
- **Застарілі чати.** Старі ендпоінти `/chats` (клієнт ↔ адмін) залишені в API, але UI їх не використовує; робочий чат — лише `/chats/order/:orderId`.
- **Одночасне прийняття.** Перевірка й запис кур'єра не в транзакції, тому race між двома кур'єрами теоретично можливий (немає гарантії на рівні БД через unique/умовний UPDATE); у тестах другий кур'єр отримує `409`.

## Документація й код

- **Розходження OpenAPI.** `/orders`, `/chats`, `/geo` й `/owner` відсутні в документі OpenAPI. Кожен задокументований ендпоінт існує двічі — у `src/routes/*` (корінь) і в `src/openapi/*` (`/api/*`) — і обробники OpenAPI переписують логіку, а не делегують, тож вони можуть розійтися.

## Тести й інструменти

- **Тести не герметичні.** Backend Vitest ходить у живий `localhost:3000` і пише в базу. `src/tests/api.test.ts` має застарілу асерцію, що очікує масив від `/products`, тоді як ендпоінт повертає `{ products, pagination }`.
- **Frontend e2e потребує запущеного сервера.** У `playwright.config.ts` немає `webServer`; запустіть `npm run dev` перед `npm run test:e2e`.
- **Лінт chef-панелі.** У `сhef-panel` немає закоміченого конфігу ESLint, тож `npm run lint` падає, доки його не додадуть. Для перевірки користуйтеся `npm run build` (`tsc -b && vite build`).

## Непослідовні форми відповідей

Форми відповідей неоднорідні: `/products` і `/categories/:slug` повертають об'єкт із `pagination`, тоді як `/categories`, `/tags`, `/orders`, `/orders/my` й `/inventory` повертають голі масиви. Клієнт має читати обробник.
